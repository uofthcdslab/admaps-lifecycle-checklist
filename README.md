# ADMAPS Lifecycle Checklist

This repository contains two complementary artifacts derived from the ADMAPS framework for high-stakes public-sector algorithmic decision-making.

## Contents

* **ADMAPS\_Lifecycle\_Checklist\_v1.pdf**  
  A one-page operational checklist intended for use in audits, design reviews, procurement discussions, and post-deployment evaluation.
* **ADMAPS\_Framework\_Companion\_v1.pdf**  
  A companion document providing conceptual grounding and interpretation of the ADMAPS framework that underpins the checklist.

## How This Is Used

The ADMAPS Lifecycle Checklist is designed for operational use. It supports structured reflection and discussion rather than scoring, certification, or compliance assessment.

In practice, the checklist is used to:

* guide multi-stakeholder conversations during audits and reviews,
* surface how algorithmic systems reshape frontline discretion and everyday work,
* support procurement and governance decisions before adoption,
* diagnose post-deployment concerns when systems are technically functional but operationally problematic, and
* structure research, teaching, and case analysis in public-sector AI contexts.

The framework companion provides theoretical context and should be consulted when deeper interpretation is needed.
